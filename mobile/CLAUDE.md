# Tracknotes (mobile/)

Expo SDK 58 / React Native 0.88 (exact pins in `package.json`), New Architecture, Expo Router, MapLibre. MapLibre needs native code, so it runs in **development builds, not Expo Go**. `ios/` and `android/` are generated by `npx expo prebuild` — never edit them. Architecture and source layout: `docs/architecture/mobile.md`.

## Rules

- **`npx expo install <pkg>`** for Expo packages, never `npm install` (`npx expo install --check` / `--fix` for mismatches).
- Screens use the `navigation/` scroll containers; raw palette tokens are import-restricted. Both are lint-enforced.
- After changing `app.json` plugins or native deps, run `npx expo prebuild --clean`, and for native deps confirm the dev build compiles (see Device check below).
- **No OTA updates:** `expo-updates` isn't installed, so every change, JS included, ships as a new build.

## Commands (from mobile/)

```bash
npm test                 # Jest (tests in __tests__/ dirs next to source)
npm run typecheck        # tsc --noEmit
npm run lint             # expo lint
npx expo-doctor          # Project health
npx expo config --json   # Check the resolved app config parses
eas build --non-interactive --profile preview --platform android   # Test APK; runbook: docs/mobile-test-build.md
```

EAS profiles (`eas.json`): `base`, `development`, `development-device`, `preview` (sideloadable `.apk`), `production` (`.aab`).

**Needs a human:** `npx expo start` (interactive; the user runs Metro in their own terminal), `eas login`, first-time iOS credential setup.

## Environment variables

`EXPO_PUBLIC_*` vars are inlined by Metro from `mobile/.env.local` — **restart Metro after changing them**. The `eas.json` env block applies only to EAS cloud builds, so each var must also be in `.env.local` for local dev. All are public URLs:

```
EXPO_PUBLIC_API_BASE_URL=http://localhost:8787          # deployed: https://api.tracknotes.info
EXPO_PUBLIC_CONTOUR_TILE_URL=https://tiles.contour-map-tiles.net   # unset: maps silently render without contours
EXPO_PUBLIC_TILE_BASE_URL=https://data.tracknotes.info       # unset: Offline Maps disables downloads
```

## Android emulator (local sessions)

When the user has the emulator (Pixel 7) and Metro running, drive it over ADB: make a change (Metro hot-reloads) → screenshot → Read the PNG → check logcat.

```bash
adb exec-out screencap -p > /tmp/screenshot.png
# Launch the dev build into the JS app (a plain `am start` lands on the Expo Dev Launcher)
adb shell am start -a android.intent.action.VIEW -d "tracknotes://expo-development-client/?url=http%3A%2F%2F10.0.2.2%3A8081" com.tracknotes.app
adb shell am force-stop com.tracknotes.app
adb shell pm clear com.tracknotes.app                 # Fresh app state
adb shell input tap 540 1200                          # also: swipe x1 y1 x2 y2 ms, keyevent KEYCODE_BACK, text "..."
adb logcat -d -t 50 ReactNativeJS:* *:E | grep -v chatty
```

**Device check after a native change** (SDK bump, native dependency): build in a checkout on disk, not under `/tmp` (RAM-backed tmpfs; a 6 GB build exhausts it), with the emulator closed while Gradle runs — `npx expo prebuild --platform android --clean --no-install && cd android && ./gradlew assembleDebug -PreactNativeArchitectures=x86_64 --max-workers=3` (~12 min) — then boot the emulator, `adb install -r android/app/build/outputs/apk/debug/app-debug.apk`, start Metro and drive the screens the change touches.
