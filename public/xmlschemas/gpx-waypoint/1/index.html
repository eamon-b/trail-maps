Tracknotes GPX waypoint extension, version 1

Namespace: https://tracknotes.info/xmlschemas/gpx-waypoint/1

A few optional fields a GPX file can hang off a waypoint, inside its <extensions>, to describe a place you leave the trail to reach: a town at the end of a road, a hut down a side track. Tracknotes writes them in its own trail files and reads them when you import a GPX file. Other programs ignore them.

Example

<gpx xmlns="http://www.topografix.com/GPX/1/1"
     xmlns:tn="https://tracknotes.info/xmlschemas/gpx-waypoint/1">
  <wpt lat="38.4967" lon="-106.3244">
    <name>Salida</name>
    <type>town-access</type>
    <extensions>
      <tn:offTrailKm>35.4</tn:offTrailKm>
      <tn:accessMode>hitch</tn:accessMode>
      <tn:acceptsBoxes>true</tn:acceptsBoxes>
      <tn:store>full</tn:store>
      <tn:accessName>Monarch Pass (US 50)</tn:accessName>
    </extensions>
  </wpt>
</gpx>

Fields

  • offTrailKm: how far the place is from the route, one way, in kilometres.
  • accessMode: how you cover that distance: foot, hitch, shuttle, boat, or on-trail for somewhere the route runs straight through.
  • acceptsBoxes: true or false, whether the place will hold a resupply box you post ahead.
  • store: what the place sells: full (a supermarket or grocery), limited (a general, convenience or camp store), meals (food to eat there, nothing to carry out) or none.
  • accessName: the name of the turn-off itself, which several places reached from one road end share.
  • offTrailAscentM and offTrailDescentM: metres climbed and descended walking in, from the route to the place.

Rules

  • Every field is optional. Each must be a direct child of the waypoint's <extensions>.
  • A value that cannot be read (an unknown accessMode, an offTrailKm that is not a number) is ignored, not guessed at.
  • The waypoint stays where you leave the trail, not at the place itself.
  • Readers match the fields by local name, so a file that declares the namespace under another prefix, or uses the earlier trail-maps namespace, still reads the same.

The full description, including how each field changes the planner's distances, is in the GPX import guide.
